Github上

下面我帮你挑选出 真正值得看的 GitHub 技术文档类 AI 学习资源，全部来自搜索结果，并附带特点介绍，方便你按需选择。

🔥 GitHub 上最值得看的 AI 学习资料（强烈推荐）

1. Awesome Artificial Intelligence（AI 全栈资源集合）

📌 地址：https://github.com/owainlewis/awesome-artificial-intelligence
这是一份被持续维护的大型 AI 工程师资源清单，涵盖：

  • AI 经典书籍
  • 深度学习与 LLM 论文
  • 工程化框架（RAG、Agents、Guardrails）
  • OpenAI Cookbook、Google/Anthropic 的 agent 指南
    适合想从 “全面了解 AI 核心技术与工程实践” 的开发者。 [[github.com]](https://github.com/owainlewis/awesome-artificial-intelligence)

2. LLM-Universe（中文、零基础也能学）

📌 地址：https://github.com/datawhalechina/llm-universe
Datawhale 出品，专为中文开发者设计的 大模型系统化教程：

  • 项目驱动学习：个人知识库助手
  • 涵盖 Prompt、RAG、向量数据库、部署
  • 教程非常清晰，小白友好 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/27149793865)

3. LLM-Course（最系统的 LLM 全流程课程）

📌 地址：https://github.com/mlabonne/llm-course
Star 4.6W+，GitHub 最热门的大模型课程之一：

  • 讲 Transformer、预训练、微调（LoRA/QLoRA）、RLHF
  • 附带大量 Colab 示例可直接跑
  • 从理论到工程部署一步到位 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/27149793865)

4. Microsoft – Generative AI for Beginners（微软官方）

📌 地址：https://github.com/microsoft/generative-ai-for-beginners
微软官方 70K+ Star 的 免费入门课程：

  • 结构化生成式 AI 入门
  • Prompt 工程、聊天机器人、RAG
  • 无需基础即可学习 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/27149793865)

5. LLM Cookbook（国内中文大模型教程）

📌 地址：https://github.com/datawhalechina/llm-cookbook
基于吴恩达 & OpenAI 的大模型课程本地化改编：

  • 中文讲解，文档完整
  • 指南涵盖 Prompt、RAG、微调
  • 对中文用户非常友好 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/27149793865)

6. LLM-Action（大模型工程实战指南）

📌 地址：https://github.com/liguodongiot/llm-action
Star 14K+，聚焦工程化落地：

  • 微调（LoRA / P-Tuning）
  • 分布式训练
  • 接入 LangChain
  • 部署 Demo
    适合想真正落地企业级 AI 项目的开发者。 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/27149793865)

7. MiniMind（低成本训练 LLM）

📌 地址：https://github.com/jingyaogong/minimind
一个让你 用 2G 显卡从0训练大模型 的项目：

  • 模型仅 26M 参数
  • 全流程训练透明
  • 适合理解 Transformer 底层 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/27149793865)

8. AiLearning（中文机器学习全套资源）

📌 地址：https://github.com/apachecn/AiLearning
早期但非常完整的中文 ML 教学资源：

  • 机器学习路线图
  • KNN、CNN、RNN、NLP 代码示例
  • 图文 + 视频 + 代码三合一
    适合打基础。 [[zhuanlan.zhihu.com]](https://zhuanlan.zhihu.com/p/101437786)

9. AI-awesome（AI 学习路线大全）

📌 地址：https://github.com/fltenwall/AI-awesome
一个 AI 学习资源索引，包括：

  • 入门 → 基础 → 进阶 → 高级 路线
  • 教材、书籍、视频课程
  • 涵盖 TensorFlow / PyTorch / 深度学习
    适合“想找一个总目录”的同学。 [[github.com]](https://github.com/fltenwall/AI-awesome)
