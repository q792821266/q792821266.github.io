神经网络

来自与Microsoft copliot的某次问答。

为什么叫神经网络。类似人脑的神经元信息传递，神经网络的计算是通过每层神经元的计算结果汇总并传去下一层直至得到输出。

本质

神经元的本质是一个计算函数，包含权重w 和 偏置b

y=f(∑i=1nwixi+b) y = f\left(\sum_{i=1}^{n} w_i x_i + b\right) y=f(i=1∑n​wi​xi​+b)

其中，xix_ixi​ 是输入，wiw_iwi​ 是对应权重，bbb 是偏置，fff 是激活函数。

权重 （Weight）

权重描述的是连接强度，连接强度意味着相关性，决定输入的重要程度。

每个输入 xix_ixi​ 都有一个权重wiw_iwi​ ：

  • 如果 wiw_iwi​ 很大 → 输入对输出非常重要
  • 如果 wiw_iwi​ 很小 → 输入影响很弱
  • 如果 wiw_iwi​ 是负的 → 输入的增加会让输出减少
  • 如果 wi=0w_i = 0wi​=0 → 该输入被网络忽略

📌 例子：识别一张猫的图片

输入 = 像素
权重学到：

  • 耳朵特征像素 → 权重高
  • 身体边缘像素 → 权重中等
  • 背景像素 → 权重接近 0

所以权重告诉网络 哪些像素对“猫”的判断重要。

偏置（Bias）

偏置的作用像是阈值与激活的起点 ，使得无相关性也能有输出

权重与偏置是可以调整的

因为它们会通过“反向传播 + 梯度下降”不断被调整：

  • 如果输出错误 → 调整权重
  • 如果触发位置不合适 → 调整偏置

最终模型就会学会正确的行为。

概念 类比 作用
权重（w） 音响音量旋钮 决定输入“声音”的大小和方向
偏置（b） 音响的“初始音量” 决定不播放音时是否有声音

全连接层的每个神经元做四件事：

  1. 接受上一层的所有输出
  2. 乘权重 + 偏置
  3. 通过激活函数得到非线性输出
  4. 输出给下一层

数学上看：层之间是矩阵乘法 + 激活

h(l+1)=f(W(l)h(l)+b(l)) h^{(l+1)} = f\left(W^{(l)}h^{(l)} + b^{(l)}\right) h(l+1)=f(W(l)h(l)+b(l))

其中：

  • h(l)h^{(l)}h(l)：上一层输出
  • W(l)W^{(l)}W(l)：权重矩阵
  • b(l)b^{(l)}b(l)：偏置向量
  • fff：激活函数

每层都对上一层进行：

  • 线性变换（组合特征）
  • 非线性（重构特征）

在全连接网络中，上一层的输出向量 h(l)h^{(l)}h(l) 作为下一层的输入。每个神经元使用各自的权重进行加权求和，再加上自己的偏置。

例如，输入层、隐藏层、输出层各有 10 个神经元，相邻层之间全连接。两组层间连接共有：

10×10+10×10=200 10 \times 10 + 10 \times 10 = 200 10×10+10×10=200

这里的 200 是连接权重的数量，不是神经元数量或完整的计算量。隐藏层和输出层另有 10+10=2010 + 10 = 2010+10=20 个偏置，因此可训练参数共 200+20=220200 + 20 = 220200+20=220 个。

通过每一层的计算，使得特征发生重构与抽象

在神经网络中：

  • 前一层 → 下一层
    会把特征重新组合、压缩、抽象。

信息被重写成更高层特征。

比如图像：

第 1 层

提取：边缘（水平、垂直、斜线）

第 2 层

组合边缘 → 得到：形状（眼睛、耳朵、轮胎）

第 3 层

组合形状 → 得到：局部对象（脸、车头、动物腿）

第 4 层

组合局部对象 → 得到：整体对象（猫、狗、汽车）

你看：

  • 层数越深 → 信息越抽象
  • 不是相关性变弱，而是表示方式变了

🔥信息不会“变弱”，而是“变形”

（像不同模块之间传递对象）

你可以类比 Java：

  • 第一层输出 List<Integer>（低层信息）
  • 第二层处理后变成 Map<Feature, Double>（结构化特征）
  • 第三层处理后变成 CategoryInfo（高级抽象）

你不会说 “List → Map → Category 时信息弱了”，对吧？

而是：

每层都把原始信息转换为更适合任务的表示（representation）。

这就是“深度学习”的“深度”的含义。

深层结构的优势就是“消除无关信息 + 强化高层信息”

例如：

  • 第 1 层会保留图像的所有像素细节（噪声也在）
  • 第 3 层会只保留眼睛、耳朵、轮廓特征
  • 第 10 层基本就只关心“这张图是否是一只猫”

越深的层：

  • 噪声被过滤
  • 关键特征被强化
  • 非关键特征被抛弃

所以从高层看低层特征，确实“相关性看起来弱了”，
但那是因为 模型变得更专注，更抽象。

特征（Feature）

特征就是“帮助做判断的观察点”。

特征 = 对输入进行某种描述、能够帮助模型判断或分类的“有意义的信号”。

在人工智能/神经网络世界里，特征有更正式、更数学化的定义，我们使用“判断猫狗”的例子理解。

它可以是：

  • 图像中的边缘、形状、纹理
  • 语言中的单词、句法、语义
  • 表格数据中的年龄、收入、偏好
  • 声音中的频率、能量、节奏

在你人类判断“猫 vs 狗”时使用的“耳朵形状、鼻子、体型”这些，其实就是高层次的特征

🎨 用猫狗判断来解释“特征”的层级

深度神经网络之所以强，是它会自己从数据中逐层学到越来越抽象的特征。

下面是一个超级直观的示例：

🟦 第一层：低层特征（Low-level Features）

从像素中提取边缘、线条、颜色梯度。

比如：

  • 垂直边缘（用来找腿、身体外形）
  • 水平边缘（用来找耳朵、嘴巴）
  • 斜线边缘（用来找脸部轮廓）
  • 纹理变化（毛发纹理）

这些是数学特征，抽象程度最低。

你人类其实不会直接用“边缘”来识别猫，但深度网络会。

🟩 第二层：中层特征（Mid-level Features）

组合上面那些边缘 → 得到局部形状。

例如：

  • 弧形轮廓
  • 耳朵尖尖结构
  • 圆形眼睛
  • 毛发区域的纹理模式

这里开始接近“猫的耳朵结构”这样的可识别单位。

🟧 第三层：高层特征（High-level Features）

能够识别具体结构：

  • 猫耳
  • 狗鼻
  • 猫的爪子
  • 狗的嘴型
  • 胡须
  • 尾巴形状

这些是你人类能理解的特征。

🟥 更高层：语义特征（Semantic Features）

最终组合成：

  • “看起来是一只猫”
  • “看起来是一只狗”

也就是：

高层特征是由低层特征逐层组合出来的高级理解。

这就是为什么深度学习叫“深度”学习：因为它学到多层次特征。

🧩 那么神经网络里的“特征”到底长什么样？

不是猫耳朵的照片！
而是一组数字向量（feature vector）。

例如：

这些数字表示模型对各种“概念”的理解程度。

对于图像，某一维可能代表：

  • “毛发程度”
  • “尖耳朵强度”
  • “圆眼睛特征”
  • “鼻子位置匹配度”

深度神经网络的工作原理就是：

把原始数据转成越来越抽象的特征向量，直到能做分类/判断

🚀 直观总结（你会非常清楚）

✔ 特征 = 有助判断的信号

你判断猫狗时用：

  • 耳朵
  • 鼻子
  • 体型
  • 爪印
  • 尾巴

这些就是高层语义特征。

✔ 神经网络不直接用这些东西（不会看到“猫耳朵”字样）

它用：

  • 边缘
  • 方向
  • 纹理
  • 曲线
  • 亮度变化

来组合成高层特征。

✔ 深度网络多层的意义在于：

把低层 → 中层 → 高层 → 语义层特征一步步构造出来。

层越深，特征越抽象，表达能力越强
