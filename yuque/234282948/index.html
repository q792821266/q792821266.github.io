日志中加入TraceID

在日志中添加 traceId 是实现分布式链路追踪和审计日志关联性的关键步骤。下面是完整的实现方案，适用于 Spring Boot + Logback + ELK 的场景。

✅ 什么是 traceId？

traceId 是一个唯一标识符，用于标记一次请求在整个系统中的生命周期。它可以帮助你：

  • 追踪请求在多个服务之间的流转
  • 将日志、审计、异常等信息关联起来
  • 在 Kibana 中快速定位某个请求的所有相关日志

🧩 实现方式

一、使用 Spring Cloud Sleuth（推荐）

如果你使用 Spring Cloud，可以直接引入 Sleuth，它会自动为每个请求生成 traceId 和 spanId，并注入到日志 MDC 中。

四、在 ELK 中使用 traceId

  • 可用于跨服务链路分析、异常定位、审计合规
